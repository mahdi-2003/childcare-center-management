# User guide — BrightStart
1. **Dashboard:** Review enrollment, staff count, classroom occupancy, and outstanding invoices.
2. **Classrooms:** Create rooms with a name, age group, and maximum capacity.
3. **Enrollment:** Save a guardian first. Then select the guardian and classroom to enroll a child. The application blocks enrollment in a full classroom.
4. **Attendance:** Select a child and date, record check-in, and optionally check-out. Re-submit for the same date to update the record.
5. **Billing:** Create an invoice for a child; record a payment against an open invoice. Balances update using an SQL LEFT JOIN and aggregation.
6. **Staff & Shifts:** Add staff, then assign a shift to a classroom. The shift report joins staff and classrooms.
